## Model Lisensi: True Perpetual vs Skema Pemeliharaan Bertingkat

Pertimbangan nomor satu yang mendorong perusahaan beralih dari software CAD sewa tahunan adalah keinginan memiliki aset software secara permanen tanpa kewajiban membayar biaya berulang.

ZWCAD memegang teguh komitmen **lisensi permanen murni (*true perpetual license*)**. Sekali perusahaan membeli lisensi ZWCAD, hak penggunaan software berlaku selamanya untuk edisi tersebut. Anda tidak diwajibkan membayar biaya tahunan, biaya langganan bulanan, ataupun denda jika memutuskan tidak melakukan upgrade di tahun-tahun mendatang.

Sebaliknya, ekosistem BricsCAD di bawah payung korporasi global kini membagi produknya ke dalam banyak tingkatan lisensi (seperti BricsCAD Lite, Pro, Mechanical, BIM, hingga Ultimate). Meskipun opsi lisensi permanen masih ada, model tersebut kerap dipaketkan dengan kontrak pemeliharaan tahunan (*Maintenance*) yang memerlukan alokasi anggaran tambahan agar Anda tetap berhak menerima pembaruan teknis.

Bagi manajemen keuangan yang menghendaki kepastian anggaran belanja modal (Capex), skema dua edisi transparan dari ZWCAD—yaitu **ZWCAD Standard** untuk kebutuhan 2D drafting murni dan **ZWCAD Professional** untuk kapabilitas 2D/3D komplit beserta pemrograman API—jauh lebih mudah diproyeksikan dalam pembukuan tahunan.

## Uji Kompatibilitas LISP dan API: Kunci Kecepatan Migrasi Drafter

Di banyak biro konsultan perencana dan kontraktor konstruksi, kecepatan kerja drafting sangat bergantung pada pustaka script AutoLISP yang dikembangkan selama bertahun-tahun.

Kehilangan fungsi LISP sama saja dengan memundurkan efisiensi tim drafter ke era manual. Pada titik ini, **ZWCAD Professional** memberikan kompatibilitas kode tingkat tinggi:

* **Membaca Script LISP Tanpa Modifikasi:** Script rutin seperti penomoran grid otomatis, pembuatan profil pipa, kalkulasi dimensi, hingga penarikan data atribut dapat langsung dijalankan menggunakan perintah `APPLOAD`.

* **Dukungan API Tingkat Lanjut:** Bagi pengembang aplikasi internal yang membutuhkan otomasi mendalam, ZWCAD Professional menyediakan lingkungan ZRX (setara ObjectARX C++), .NET, dan VBA tanpa mewajibkan perusahaan melompat ke edisi berbiaya sangat tinggi.

* **Antarmuka Akrab Tanpa Training Ulang:** Tim drafter Anda dapat memilih tampilan Classic AutoCAD dengan toolbar floating atau tampilan Ribbon modern. Seluruh tombol pintasan keyboard standar tetap berfungsi normal, memastikan proses migrasi berlangsung tanpa jeda produksi.

## Performa Buka File DWG Skala Besar: Mesin Multi-Core 2026

File gambar kerja masterplan kawasan industri, denah jalur subway, atau fabrikasi struktur baja raksasa kerap mencapai ukuran ratusan megabyte dan sarat dengan ratusan ribu entitas garis.

ZWCAD 2026 dirancang dengan arsitektur mesin grafis terkini yang memaksimalkan pemrosesan multi-core pada prosesor modern:

* **Waktu Buka File Lebih Singkat:** Beban komputasi pembacaan geometri didistribusikan merata ke seluruh inti prosesor, mengurangi waktu tunggu drafter saat membuka file DWG kompleks.

* **Operasi Pan dan Zoom Mulus:** Akselerasi perangkat keras kartu grafis (GPU) menjaga stabilitas frame-rate saat menjelajahi denah padat, mencegah gejala freeze atau layar putih (*not responding*).

* **Fitur Cerdas Smart Plot:** Fitur bawaan ZWCAD ini secara otomatis mendeteksi batas frame gambar dalam satu berkas DWG dan mencetaknya menjadi ratusan lembar PDF terpisah dalam sekali klik—menghemat waktu berjam-jam saat persiapan berkas tender.

> **Catatan Penting:** Di ZWCAD Professional, fitur Smart Plot dan dukungan penuh AutoLISP sudah terintegrasi secara bawaan. Anda tidak perlu membeli modul tambahan atau add-on berbayar hanya untuk mencetak ratusan sheet gambar tender secara otomatis.

## Kebijakan Zero Dongle Fisik: Distribusi 100% Digital & Bebas Risiko

Salah satu risiko operasional yang sering dikeluhkan tim pengadaan di masa lalu adalah ketergantungan pada perangkat keras dongle USB fisik. Dongle mudah patah di port laptop saat dipindahkan, rawan tertinggal di lokasi proyek, atau tertahan berhari-hari dalam pengiriman logistik antar-pulau.

**Central CAD (PT Hetra Teknologi Indonesia)** menerapkan kebijakan **Zero Dongle Fisik**:

* **Pengiriman Kode Softkey Digital Resmi:** Seluruh lisensi diterbitkan 100% secara digital via email resmi perusahaan dalam kurun waktu normal 2 hari kerja. Kode Softkey 24-digit resmi terdaftar langsung di basis data prinsipal global ZWSOFT.

* **Aktivasi Mandiri & Return License:** Drafter dapat memindahkan lisensi stand-alone dari PC kantor ke laptop kerja secara mandiri hanya dalam hitungan detik melalui menu *Return License*.

* **Mendukung Kerja 100% Offline via Request XML:** Untuk instalasi komputer di ruang workshop rahasia atau site tambang terpencil tanpa akses internet, aktivasi dapat diselesaikan melalui mekanisme pertukaran file XML offline yang aman.

* **Network Floating dengan Borrow License 180 Hari:** Untuk lisensi jaringan terpusat pada server kantor, engineer lapangan yang hendak dinas ke site proyek terpencil dapat meminjam (*borrow*) lisensi hingga 180 hari tanpa perlu terhubung ke jaringan server selama periode penugasan.
