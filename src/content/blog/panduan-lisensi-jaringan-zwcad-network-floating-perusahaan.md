## Apa Itu Lisensi Jaringan (Network Floating License)?

Lisensi Jaringan adalah sistem pengelolaan lisensi terpusat di mana master lisensi dipasang pada satu server kantor (menggunakan aplikasi ZWSOFT Network License Manager).

Ketika staf drafter membuka aplikasi ZWCAD di komputernya, software akan secara otomatis meminta izin (*borrow/checkout token*) ke server melalui koneksi jaringan lokal (LAN) atau VPN kantor. Begitu drafter selesai dan menutup aplikasi, lisensi tersebut **kembali ke server dan bisa langsung dipakai oleh staf lain**.

### Ilustrasi Penghematan Nyata:
* **Kasus:** Perusahaan Anda memiliki total **30 orang staf teknis**, namun hanya sekitar **10 hingga 12 orang** yang menggambar pada saat bersamaan.
* **Dengan Skema Standalone:** Anda wajib membeli 30 unit lisensi.
* **Dengan Skema Network Floating:** Anda cukup membeli **10 hingga 12 seat Network License**. Seluruh 30 komputer staf dapat diinstal ZWCAD dan bebas menggunakannya secara bergantian tanpa melanggar hukum hak cipta software.
* **Hasil Finansial:** Perusahaan menghemat biaya investasi hingga **60%** di awal pengadaan.

## Fitur Unggulan ZWCAD Network License Manager

Sistem lisensi jaringan ZWCAD dirancang dengan fleksibilitas tinggi untuk mendukung kebutuhan lapangan:

1. **Borrow License (Peminjaman Lisensi Offline):** Jika ada insinyur yang harus melakukan survei atau bekerja di lokasi proyek lapangan tanpa koneksi internet/VPN, lisensi dapat 'dipinjam' ke laptop selama durasi tertentu (misal: 14 atau 30 hari). Selama masa peminjaman, ZWCAD di laptop dapat dijalankan 100% offline.
2. **Monitoring Pemakaian Real-Time:** Administrator IT perusahaan dapat memantau secara langsung siapa saja personil yang sedang aktif menggunakan software dan jam penggunaannya melalui web dashboard server.
3. **Fleksibilitas VPN & Multi-Cabang:** Satu server lisensi di kantor pusat dapat melayani kebutuhan drafting di kantor cabang atau pabrik di luar kota selama terhubung melalui jaringan VPN korporat yang aman.
4. **Instalasi Server Bebas Biaya Tambahan:** Software License Manager disediakan secara gratis tanpa biaya langganan server tahunan.
